首次使用？跟我三步起跑
  1. 先确认下方「环境」卡片里 node / pnpm / git 都已就绪——缺失时可一键自动安装或取官方指引。
  2. 还没有 DeepSeek Harness 源码？在「环境」卡片点「获取 Harness 源码」，或到「其它设置」填仓库路径。
  3. 回顶部点「构建 Harness」，完成后到左侧「启动 web」点「启动 dsh web」即可打开界面。
